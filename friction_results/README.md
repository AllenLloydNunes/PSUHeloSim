# Friction results — figure index

Copies of the friction-related figures, gathered in one place. Originals live in `../figures/`
and are regenerated by the scripts listed below; re-run those and re-copy if parameters change.

All runs: μ = 0.6, v_bl = 0.1 ft/s = 0.03048 m/s (matched to UH-60 `LG_VBL`), m = 1000 kg,
k = 6.54e4 N/m, c = 2800 N·s/m, RK4, 5° incline.

## From `run_all_tests` (step 3, `test_step3_friction_slope.m`)

| file | shows |
|---|---|
| `test3A_hold_on_5deg_slope_*.png` | Settle and hold on the slope at dt = 1 ms. Creeps downhill at the analytic 4.444 mm/s; friction stays below μN (ratio 0.146). |
| `test3B_slide_downhill_to_stop_*.png` | Tail-first slide downhill from 3 m/s. Stops in 0.8984 m vs 0.8975 m analytic (0.10%). |
| `test3B_slide_uphill_to_stop_*.png` | Nose-first slide uphill from 3 m/s. Stops in 0.6662 m vs 0.6690 m analytic (0.42%). |
| `test3C_integrator_stability_seeded_runs.png` | Five v_bl / dt configurations with a lateral velocity seed; linear stability prediction matches the simulation in all five. |

Each 3A/3B case has four panels: `_position`, `_attitude`, `_gear_loads` (normal force, friction vs μN, penetration), `_energy`.
